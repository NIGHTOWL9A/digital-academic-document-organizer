# Digital Academic Document Organizer

Java application for organizing academic resources by subject, semester, type, keywords and file path.

## Current version
- Add document metadata
- Search documents
- List documents
- Object-oriented design

## Run
```bash
cd src
javac Document.java DocumentOrganizer.java
java DocumentOrganizer
```

## Version 2 roadmap
- JavaFX GUI
- MySQL and JDBC
- File upload/open functionality
- Subject and semester filters
